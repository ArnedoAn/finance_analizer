# API endpoints v3

Mount under /api/v1. X-API-Key is required except health/live and health/ready. PHONE_API_KEY is accepted only by GET auth/check and POST notifications/webhook; FINANCE_API_KEY also works there and is required everywhere else. Both keys require at least 32 characters at startup. Ten invalid keys per socket-peer IP per minute trigger 429 for further invalid attempts; valid scoped keys always pass and never clear the failure bucket. Share get_db so tests can override it. Commit webhook ingestion before background processing in a fresh session, return inbox_id for accepted and duplicate/ignored events, and retain truncated raw text according to the v3 retention policy. Unexpected errors return sanitized JSON 500 responses; standard FastAPI validation/auth errors remain JSON.

Inbox responses use an explicit public field allowlist and never expose claim_token, claim_until, or future internal columns. Only admin GET inbox/{item_id}?include_raw=true returns raw_text; the default is false. Lists, manual transactions, review actions, and reprocess responses omit raw_text. Manual requests require client_ref, validate before processing (422), and return 502 with the durable failed inbox_id on submission failure; do not automatically retry manual failures. Review supports approve/reject/edit/void and reprocess; updates and voids propagate to Firefly. Sender learning only proposes pending approvals; /senders/seed does not exist.

GET health reads IMAP last_poll_at and consecutive_failures from the database without logging into mail. Never-polled accounts or polls older than two hours are stale and degrade health; any consecutive failure also degrades health. Explicit POST mail/accounts/{name}/test reserves one login per account per minute atomically in the notifications table with key mail-test:{name}, committed before IMAP login; repeated tests return 429 with Retry-After: 60. This reservation never sends Telegram. Production disables docs/OpenAPI unless EXPOSE_DOCS=true. Public probes must never expose secrets.
