# External clients v2

FireflyClient uses one configured owner token; never per-user caches or asset creation. LLMClient uses OpenAI-compatible OpenCode Go model order, validates JSON and optionally falls back to direct DeepSeek; Bearer/User-Agent and stable cycle x-opencode-session headers. IMAPClient uses imaplib via asyncio.to_thread, EXAMINE/BODY.PEEK and persistent UID highwater; Gmail/Yahoo/iCloud/custom credentials, no OAuth. Close HTTP clients during lifecycle cleanup. Never print secrets or financial bodies. Tests must mock external I/O unless explicitly live-opted-in.
