# External clients v2

FireflyClient uses one configured owner token; never per-user caches or asset creation (the only non-merchant account it creates is the explicit liability of a debt, ``create_liability``; ``create_account`` stays expense/revenue only). ``TrmClient`` reads the official TRM from datos.gov.co (SODA) with a timeout; failures are ``TrmError``. LLMClient uses OpenAI-compatible OpenCode Go model order, validates JSON and optionally falls back to direct DeepSeek; Bearer/User-Agent and stable cycle x-opencode-session headers. IMAPClient uses imaplib via asyncio.to_thread, EXAMINE/BODY.PEEK and persistent UID highwater; Gmail/Yahoo/iCloud/custom credentials, no OAuth. Close HTTP clients during lifecycle cleanup. Never print secrets or financial bodies. Tests must mock external I/O unless explicitly live-opted-in.
