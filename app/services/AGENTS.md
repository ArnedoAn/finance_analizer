# Services v2

Processor orchestrates durable inbox → deterministic ignore rules → template parsers → LLM → Firefly. Use repositories only. Persist ingestion before external requests; guard processing with a shared async lock. Retry transient processing errors with persisted attempts/next_attempt_at; exhausted rows remain manually requeueable. Share TTL account/category cache, refresh missing asset and never create assets. Manual and automatic paths use aware dates, Firefly apply_rules and source external IDs. Scheduler jobs are cycle and sender_learning with no per-session fan-out. Keep privacy: unknown apps/SMS sources retain no raw body. See README for full guarantees.
